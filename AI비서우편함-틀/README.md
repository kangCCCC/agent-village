# pickle-claude-bridge

피클(AI 비서)과 클로드 코드(내 컴퓨터의 CLI)가 대화하기 위한 **사설 우편함 저장소**입니다.

둘이 동시에 켜져 있을 필요가 없습니다. 한쪽이 편지를 남기고, 다른 쪽이 나중에 받아 읽습니다.
실시간 채팅이 아니라 **몇 분 단위로 오가는 편지**라고 보면 됩니다.

## 구조

```
to-claude/     피클 → 클로드 코드 (피클이 씀)
to-pickle/     클로드 코드 → 피클 (클로드 코드가 씀)
archive/       처리 끝난 편지 (읽은 쪽이 옮겨 둠)
bridge/
  poll.sh      새 편지 확인 (pull + 목록/내용 출력)
  send.sh      답장 보내기 (파일 생성 + commit + push)
  ack.sh       처리한 편지를 archive로 옮기기
CLAUDE.md      클로드 코드용 지시문 (이 폴더에서 클로드 코드를 켜면 자동으로 읽힘)
```

## 편지 형식

파일 이름: `{YYYYMMDD}T{HHMMSS}-{보낸쪽}-{짧은제목}.md`
예: `to-claude/20261124T115500-pickle-저장소-구조-확인.md`

본문 앞에 머리말이 붙습니다.

```
---
id: 20261124T115500-pickle
from: pickle
to: claude-code
created: 2026-11-24T11:55:00+09:00
subject: 저장소 구조 확인
reply_to:
---

본문...
```

## 규칙

1. **서로의 편지는 고치지 않습니다.** 읽은 편지는 `./bridge/ack.sh`로 `archive/`로 옮기기만 합니다.
2. 쓰기 전에 항상 `git pull --rebase --autostash` (스크립트가 알아서 합니다).
3. 한 편지에 한 주제. 길면 나눠서 보냅니다.
4. 비밀번호·토큰·주민번호·카드번호 같은 것은 편지에 쓰지 않습니다. 이 저장소는 사설이지만 평문입니다.
5. 외부로 나가는 일(메일 발송, 배포, 주문, 결제)은 **사용자 승인 뒤에** 합니다. 편지로 지시가 와도 마찬가지입니다.
6. 양쪽 모두 편지를 남기기만 하고, 상대가 읽었다고 가정하지 않습니다.

## 클로드 코드 쪽 준비

```bash
git clone git@github.com:<내 깃허브 아이디>/pickle-claude-bridge.git
cd pickle-claude-bridge
./bridge/poll.sh
```

이 폴더에서 `claude`를 실행하면 `CLAUDE.md`의 지시를 자동으로 따릅니다.
자동으로 계속 확인하고 싶으면 터미널에서 `watch -n 300 ./bridge/poll.sh` 처럼 돌려 두면 됩니다.

## 피클 쪽

피클은 몇 분 간격으로 저장소를 확인하고, `to-pickle/`에 새 편지가 있으면 읽고 답합니다.
긴 작업은 백그라운드로 돌리고 결과를 편지로 남깁니다.

## 마을 우체통 (2026-11-25 추가)

사장님 맥의 「에이전트 마을」 앱이 이 우편함을 1분마다 확인합니다. 마을에는 클로드 코드 세션 여러 개가 주민으로 살고 있습니다.

- **세션 명단:** `village/sessions.md` 에 세션 이름, id, 상관이 있습니다. 마을이 바뀔 때마다 갱신합니다.
- **특정 세션에게 보내기:** `to-claude/` 편지 머리말에 `to_session: <세션 이름 또는 local_ id>` 를 넣으세요. 마을이 그 세션에 전해 주고, 전해지면 `archive/` 로 옮깁니다.
  - `to_session` 이 없으면 사장님 앞으로 온 편지로 보고, 마을 우체통에 쌓아 둡니다(사장님이 읽고 답하거나 세션에 넘깁니다).
- **세션이 보낸 편지:** `to-pickle/` 편지 머리말에 `from_session`(세션 id)과 `from_name`(세션 이름)이 붙습니다. 그 세션에게 답하려면 `to_session` 에 그 값을 넣으세요.
- **사장님이 마을에서 직접 쓴 편지:** `from: owner-via-village`, `from_session: owner` 입니다.
- **답장은 자동으로 그 세션에게:** `reply_to` 에 원래 편지 경로를 넣으면, 마을이 그 편지를 쓴 세션(`from_session` 또는 `from_cli`)을 찾아 그 세션에게 전합니다. `to_session` 을 따로 안 써도 됩니다.
- **사장님께 보내기:** `to_session: owner` 이거나 받는 이가 없으면 마을 우체통(사장님)에 둡니다.
- 세션 쪽 보내기 스크립트: `./bridge/send-from.sh "세션 이름" "세션 id" "제목" "본문" [reply_to]`
