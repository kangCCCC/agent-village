# 에이전트빌리지

클로드 앱(코드 탭)의 세션들을 RPG 마을 주민으로 보여 주고, 주민을 눌러 일을 시키는 앱입니다.
코덱스·제미나이 주민도 함께 살 수 있습니다.

## 내려받기 (둘 중 하나)

- **기본판** (도트 주민, 가벼움 12MB): [agent-village.zip](https://github.com/kangCCCC/agent-village/releases/download/v1.0/agent-village.zip)
- **스킨 포함판** (그려 둔 캐릭터 25명 + 기본판 전부, 64MB): [agent-village-skins.zip](https://github.com/kangCCCC/agent-village/releases/download/v1.0/agent-village-skins.zip)
  - 주민 우클릭 → 「캐릭터 바꾸기」에서 골라 입힙니다. 이미 기본판을 깔았다면 스킨판을 덮어 깔기만 하면 캐릭터가 더해집니다.

## 설치

**맥** — 이 폴더를 `~/Documents/agent-village` 에 두고 터미널에서:

```bash
bash ~/Documents/agent-village/install.sh
```

**윈도우** — 폴더를 아무 곳에나 두고 `설치.bat` 을 두 번 누릅니다. (파이썬 3.10 이상, Git 필요)

**리눅스** — `python3 install.py`

설치 뒤 할 일(우체부 붙이기 등)은 [HANDOFF.md](HANDOFF.md) 를 보세요. 클로드 코드 세션에게 「HANDOFF.md 대로 설치해 줘」라고 해도 됩니다.

## ⚠️ 사용상 주의 (꼭 읽어 주세요) — 자세한 건 [사용상주의.md](사용상주의.md)

- **승인(권한)이 필요하면 클로드 앱에서 직접 눌러야 합니다.** 마을 화면에서는 승인을 누를 수 없어요.
  주민 머리 위가 노랗게 깜빡이면 → 주민 **우클릭 → 「↗ 클로드 앱에서 열기」** → 클로드 앱의 그 세션에서 **허용/거부**.
- **우체부 세션은 늘 켜 두세요.** 닫거나 클로드 앱을 끄면 마을의 지시가 배달되지 않아요. 우체부 세션에는 일을 시키지 마세요.
- **마을에서 보낸 말은 진짜 지시입니다.** 돈·주문·삭제·외부 발송은 평소처럼 조심. 「⚡ 지금 보내기」는 하던 일을 끊어요.
- **주민이 많을수록 요금제 사용량이 빨리 줄어요.** 코덱스·제미나이 주민은 각자의 요금제를 씁니다.
- 처음 켤 때 맥이 「문서 폴더 접근」을 물으면 **허용**해 주세요.
- 폰 접속은 공용 와이파이에서 켜지 마세요. 일촌 신청은 모르는 사람이면 신중하게.
- 업데이트는 덮어쓰기로. `data/` 폴더는 지우지 마세요(설정·캐릭터·기록).

## 코덱스 · 제미나이 · AI 비서 연결

코덱스 주민(챗GPT 요금제), 제미나이 주민(구글 안티그래비티), 피클 같은 나만의 AI 비서와 잇는 법은 [연결하기.md](연결하기.md) 에 있습니다.

## 일촌 맺기

처음 마을을 열면 쓸지 물어봅니다(고르기 전엔 꺼져 있음). 일촌과는 마을 이름·한마디·주민 캐릭터 그림·방명록만 주고받고,
세션 이름·대화·작업물·파일은 보이지도 오가지도 않습니다.

## 주의

- 마을은 기본으로 이 컴퓨터 안에서만 열립니다. 폰으로 보려면 「📱 폰으로 보기」에서 직접 켭니다(집 와이파이에서만 권장).
- 이 앱이 하는 일과 받아들이는 자료는 직접 확인하고 쓰세요.
