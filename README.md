# 에이전트빌리지

클로드 앱(코드 탭)의 세션들을 RPG 마을 주민으로 보여 주고, 주민을 눌러 일을 시키는 앱입니다.
코덱스·제미나이 주민도 함께 살 수 있습니다.

## 설치

**맥** — 이 폴더를 `~/Documents/agent-village` 에 두고 터미널에서:

```bash
bash ~/Documents/agent-village/install.sh
```

**윈도우** — 폴더를 아무 곳에나 두고 `설치.bat` 을 두 번 누릅니다. (파이썬 3.10 이상, Git 필요)

**리눅스** — `python3 install.py`

설치 뒤 할 일(우체부 붙이기 등)은 [HANDOFF.md](HANDOFF.md) 를 보세요. 클로드 코드 세션에게 「HANDOFF.md 대로 설치해 줘」라고 해도 됩니다.

## 일촌 맺기

처음 마을을 열면 쓸지 물어봅니다(고르기 전엔 꺼져 있음). 일촌과는 마을 이름·한마디·주민 캐릭터 그림·방명록만 주고받고,
세션 이름·대화·작업물·파일은 보이지도 오가지도 않습니다.

## 주의

- 마을은 기본으로 이 컴퓨터 안에서만 열립니다. 폰으로 보려면 「📱 폰으로 보기」에서 직접 켭니다(집 와이파이에서만 권장).
- 이 앱이 하는 일과 받아들이는 자료는 직접 확인하고 쓰세요.
